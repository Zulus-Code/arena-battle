# Arena Battle

Танковый бой на арене от третьего лица. Игра построена на Three.js и React Three Fiber.

## Технологии

- **Движок:** Three.js + React Three Fiber
- **Физика:** кастомная (circle‑circle коллизии)
- **Стейт‑менеджмент:** Zustand
- **Сборка:** Vite
- **Язык:** TypeScript

## Управление

| Клавиша | Действие |
|---|---|
| **W** / **↑** | Вперёд |
| **S** / **↓** | Назад |
| **A** / **→** | Поворот вправо |
| **D** / **←** | Поворот влево |
| **Space** / **ЛКМ** | Стрельба |
| **Shift** | Активировать щит |
| **Esc** | Пауза |

## Как запустить

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовый билд — один файл `dist/index.html` (всё встроено).

## Геймплей

- Уничтожайте врагов на арене
- Собирайте пикапы: аптечка, щит, патроны и усиления
- Три уровня сложности с разными типами противников (Scout, Tank, Boss)
- После смерти — возрождение до трёх раз
