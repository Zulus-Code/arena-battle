# Arena Battle

Боевые багги на арене от третьего лица. Мини-3D-шутер в браузере: волны врагов, сбор очков, три типа противников.

## Управление

- `W` / `S` — вперёд / назад
- `A` / `D` — руль (корпус поворачивается, боком машина не едет)
- мышь — башня отдельно от корпуса
- `ЛКМ` / `Space` — огонь
- жёлтый луч от ствола — куда именно полетят пули
- `R` — рестарт после смерти

## Стек

- **three.js r187** — рендеринг, `WebGPURenderer` с автоматическим откатом на WebGL2 (на Linux-Firefox пока именно WebGL2)
- **TypeScript + Vite 8** — без React, весь игровой цикл на `requestAnimationFrame`
- **Node test runner** — детерминированные тесты симуляции

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run typecheck   # tsc
npm test            # симуляция: движение, стрельба, урон, стены
npm run build       # прод-сборка в dist/
```

## Структура

```
src/config.ts   все цифры баланса (скорость, HP, урон, волны)
src/rules.ts    чистая геометрия: движение по кругам, столкновения, RNG
src/game.ts     симуляция: игрок, враги, пули, волны (без three.js)
src/scene.ts    арена, свет, препятствия
src/meshes.ts   низкополигональные модели багги
src/input.ts    клавиатура + мышь
src/hud.ts      DOM-оверлей: HP, счёт, экраны
src/main.ts     рендерер, камера, игровой цикл
```

Симуляция (`game.ts`, `rules.ts`) не зависит от three.js — поэтому её можно тестировать без браузера.
